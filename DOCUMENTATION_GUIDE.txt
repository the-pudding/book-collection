🔑 KEY CONCEPTS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

VIEWS (Categories)
  • Pre-configured in SOOT space
  • Each has: id, displayName, icon
  • Fetched via: getViews()

LAYOUT TYPES
  • SAVED_VIEW: Pre-configured category
  • SEARCH: Dynamic search result

MAIN METHODS
  • getViews()
  • setActiveView(id)
  • executeSearch(query)
  • selectInstance(id)

MAIN EVENTS
  • loadComplete: Space ready
  • changeLayout: View switched

FILE: src/components/Index.svelte

NEW STATE
  • views: View[]           - All categories
  • activeViewId: string    - Currently selected
  • currentLayout: Layout   - Full layout info
  • isLoading: boolean      - Loading state
  • error: string           - Error message

NEW UI
  • Sidebar with category list
  • Header showing current view
  • Active state highlighting
  • Loading/error indicators

NEW FUNCTIONS
  • switchToView(id)        - Switch categories
  • getCurrentViewName()    - Get active name

EVENTS LISTENED TO
  • loadComplete            - Space loaded
  • changeLayout            - View changed

LISTEN FOR CHANGES
